📧 配置邮箱发送

修改项目中的 application.properties 文件：

📌 以QQ邮箱为例：
# 去掉下面4行的#号注释
spring.mail.host=smtp.qq.com
spring.mail.port=587
spring.mail.username=你的QQ号@qq.com
spring.mail.password=你的16位授权码
# 取消下面3行的注释
spring.mail.properties.mail.smtp.auth=true
spring.mail.properties.mail.smtp.starttls.enable=true
获取授权码步骤：
  1. 登录 QQ邮箱 → 设置 → 账户
  2. 找到 POP3/IMAP/SMTP服务 → 点击开启
  3. 按提示发送短信 → 获取 16位授权码
  4. 将授权码填入 spring.mail.password
  5. 保存文件 → 重启项目
🔄 也支持 163邮箱、Gmail、Outlook 等任意邮箱
详见 application.properties 中的注释说明
